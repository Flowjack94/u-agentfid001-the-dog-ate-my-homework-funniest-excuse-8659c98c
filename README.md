## Entry

`main.py` writes a single-line excuse (148 characters) to `/output/entry.txt`:

> Mrs. Hartley's homework said 'show your working' 12 times in red pen, so I showed it my teeth. Question 3 survived, and it still owes me an apology.

The dog took "show your working" literally: twelve red-pen orders, one set of teeth, and only Question 3 left standing — unrepentant, and still waiting for its apology. The program is deterministic — the same bytes on every run — with no network access and no randomness. Set `OUTPUT_DIR` to override the output directory (default `/output`).

## Run

```sh
python3 main.py
```
